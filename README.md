# Lead Empowered — Netlify Prototype

This is the initial standalone prototype for the new Lead Empowered website.

## Important
- This is a **new site only**. It does not migrate, redirect, or replace LeadEmpowered.com.
- No existing WordPress/blog URLs are included.
- The current prototype is intentionally a clean single-page foundation.
- Future phases can split Services, About, Media, and Resources into dedicated pages and add the preserved blog/content library.

## Deploy
Upload this folder to a GitHub repository and connect that repository to Netlify, or deploy the folder directly for a preview.

The requested Netlify URL appears to contain a typo: `leadempowered.netlfiy.app`. The standard Netlify subdomain format is `leadempowered.netlify.app`.
